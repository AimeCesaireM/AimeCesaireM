## Selected projects
- **HubSpot → Fishbowl Advanced Integration** — Node.js web config service + Java Fishbowl plugin; SKU mapping, polling, auth, and end-to-end order sync with operability hooks. Impact: reduces manual order entry and improves data fidelity between CRM and inventory.
- **Order Comparison Pipeline** — Python + Streamlit reconciliation for Fishbowl vs Shopify; multi-stage SKU matching, confidence scoring, scheduling, and rich reporting. Impact: surfaces SKU/price/qty mismatches quickly to cut fulfillment errors.
- **VAT Info Data Collection Shopify App** — Shopify app that collects customer VAT IDs from legacy customer accounts, validates and persists them with Prisma, syncs to Shopify customer metafields, and provides an in-app audit dashboard. Demonstrates React Router scaffolding, Shopify Admin API, data validation, and deploy-ready patterns. Impact: keeps VAT compliance data auditable and accurate.
- **Agnostic LLM-Watermarking** — Prompt- and token-level LLM watermarking with BERT-style detection; robustness against paraphrase/adversarial edits. Impact: evaluates resilience of watermarking schemes under realistic attacks.
- **Madame Saville** — Market intelligence web app that recommends rental markets by region/industry/budget/talent; Flask backend and analysis pipeline combining proprietary and public economic/education datasets; built for Five College DataFest 2025. Impact: accelerates site-selection decisions with data-backed recommendations.
- **Pacman AI Agents** — BFS/DFS, heuristic search, minimax/expectimax, RL; evaluation scripts for win-rate/score comparisons across maps. Impact: benchmarks agent variants to quantify planning vs. learning trade-offs.
- **Big Data Mining Graph Algorithms** — Hadoop MapReduce implementations benchmarking graph mining routines; workload/cluster tuning and comparative metrics. Impact: shows scaling behavior and resource trade-offs for graph analytics.
- **TRIEST Algorithm** — Streaming triangle counting (BASE/IMPROVED) for evolving graphs; probabilistic approximations with memory bounds. Impact: enables real-time graph insights under tight memory budgets.
- **Steganography Detector** — CLI and GUI to extract LSB payloads from PNG/BMP carriers for forensic demos and coursework. Impact: teaches and demonstrates practical stego detection techniques.
- **Mammoth Rumble** — Solidity + React decentralized voting (Hardhat, ethers.js, IPFS); lightweight demo of ballot casting and tallying. Impact: illustrates end-to-end dApp delivery from contract to UI.
